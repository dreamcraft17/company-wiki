# Source 03 — Nielsen Norman Group Homepage Usability Guidelines

- **URL:** https://www.nngroup.com/articles/113-design-guidelines-homepage-usability/
- **Type:** Secondary / UX usability reference
- **Accessed:** 2026-09-17
- **Relevance:** Guidance on homepage taglines, customer-value language, differentiation, and priority tasks.

## Verbatim excerpts

> “A simple tagline that stated this differentiator would give users unfamiliar with the company an instant sense of what the site can offer them.”

> “Emphasize the highest priority tasks so that users have a clear starting point on the homepage.”

## Application

The eyebrow should orient the visitor to the audience/context, while the H1 should carry the differentiating promise. The current H1 already does this; the eyebrow should remain short enough not to compete with it.
