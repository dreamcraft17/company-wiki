# F2 — Keyword Placement

## Finding

Keep `50–300 karyawan` in the supporting copy and metadata, not in the eyebrow. Keep `HRIS`, `absensi`, `payroll`, `BPJS/PPh 21`, and `audit trail HR` in the title/subheading and body copy.

## Rationale

The target headcount is useful qualification information, but it is not the main reason the page is relevant. The operational context—multi-cabang and HR control—is more useful in the first visual label. Metadata and supporting text can carry the qualification detail without making the eyebrow long.

## Limits

No search volume, impression, click-through, or lead-quality data was available. This is a copy architecture recommendation, not an SEO ranking prediction.
