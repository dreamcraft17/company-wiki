# F4 — Recommended dnPeople direction: operational editorial

Recommended direction: **Operational Editorial**.

- Warm off-white canvas rather than a dark gradient-first shell.
- Ink navy and one restrained teal/green accent; no purple/blue gradient blobs.
- 4–8px radius for most controls; 0–12px only where grouping helps.
- Thin rules, compact evidence rows, visible labels, and strong table headers.
- One “evidence slip” motif: actor, branch, timestamp, reason, approval state.
- Typography with one sans family plus optional mono only for IDs/timestamps.
- Human detail through real workflow language and data states, not stock illustrations.
- Small moments of depth only when they signal layer or action.

This is an inference from the source set and the current dnPeople codebase; validate with 5–8 target users before a full application-wide migration.
