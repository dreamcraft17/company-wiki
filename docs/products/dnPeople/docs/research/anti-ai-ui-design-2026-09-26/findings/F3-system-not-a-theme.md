# F3 — The visual language must be a system

Material and Apple both treat hierarchy, typography, surfaces, and interaction states as a system. The strongest route for dnPeople is a small, intentional token set rather than a collection of one-off “designed” screens.

Design implication: limit typefaces and weights, use high-contrast text, define borders and surfaces as semantic tokens, and make status/action states explicit. Keep color for meaning: brand, selected, success, warning, error—not for ambient decoration.
