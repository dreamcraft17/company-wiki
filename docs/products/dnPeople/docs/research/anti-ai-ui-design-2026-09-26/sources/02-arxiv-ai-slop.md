# Source 02 — arXiv: AI slop in software development

- URL: https://arxiv.org/abs/2603.27249
- Type: academic preprint / qualitative analysis
- Retrieved: 2026-09-26
- Credibility: medium-high for describing practitioner discourse; scope is software-development artifacts, not visual UI testing.

## Relevant evidence

The study analyzed 1,154 posts across 15 Reddit and Hacker News discussions. It groups concerns into review friction, quality degradation, and structural forces. The design-relevant inference is that superficial competence and low-cost mass production can shift evaluation burden onto reviewers and reduce trust.

Short quote: “AI slop is not merely a code quality issue: It is a sociotechnical problem.”

## Use in decision

Treat “anti-slop” as a craft and accountability problem. For dnPeople, require explicit rationale for repeated visual patterns and human review of the workflow, not only a surface-level theme change.
