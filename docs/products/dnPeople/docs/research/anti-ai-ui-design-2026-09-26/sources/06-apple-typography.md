# Source 06 — Apple HIG: Typography

- URL: https://developer.apple.com/design/human-interface-guidelines/typography
- Type: primary platform design guidance
- Retrieved: 2026-09-26
- Credibility: high for typography/accessibility guidance.

## Relevant evidence

Apple treats type choices as a mechanism for legibility, hierarchy, brand, and consistency. It recommends avoiding overly light weights at small sizes, preserving relative hierarchy, and limiting typefaces.

Short quote: “Avoid light font weights.”

## Use in decision

Use a small type system with stronger labels and readable body text. Avoid the low-contrast gray-on-gray microcopy common in generated SaaS layouts.
