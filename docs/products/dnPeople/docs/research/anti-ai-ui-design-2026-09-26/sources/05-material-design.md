# Source 05 — Material Design introduction

- URL: https://m1.material.io/
- Type: primary design-system documentation
- Retrieved: 2026-09-26
- Credibility: high for the principles it defines; not a mandate to copy Material styling.

## Relevant evidence

Material frames UI as a system grounded in paper and ink, with surfaces and edges providing cues. It also says typography, grids, spacing, scale, color, and imagery establish hierarchy and focus; actions should be immediately apparent and motion should clarify continuity.

Short quote: “An emphasis on user actions makes core functionality immediately apparent.”

## Use in decision

Build dnPeople around an explicit information hierarchy and meaningful states. Borrow the reasoning—surface, edge, action, continuity—not the default indigo/card aesthetic.
