# Source notes — market and privacy

## Workday — self-service agent

Official product positioning connects HR assistant value to answers grounded in company policies, live HR data, security context, and guided employee actions. This supports the inference that “chat” is not the product moat; trusted context and workflow completion are.

Source: [Workday Self-Service Agent](https://www.workday.com/en-us/artificial-intelligence/ai-agents/self-service.html)

## Mekari Talenta — local category signal

Mekari Talenta positions AI around asking HR data and getting insights from employee, attendance, payroll, and reimbursement data. Its broader HRIS positioning also includes employee self-service and multi-branch operations. This means dnPeople should not claim that “having AI” alone is unique in Indonesia.

Sources: [Talenta AI](https://www.talenta.co/en/features/talenta-ai/), [Talenta HRM](https://www.talenta.co/solusi/software-hrm/)

## OpenAI — provider data controls

OpenAI states that business/API inputs and outputs are not used to train models by default, while the API documentation separately notes abuse-monitoring logs and retention controls. Product promises still need to state what dnPeople sends, what is redacted, retention, deletion, and which provider configuration is used.

Sources: [OpenAI business data privacy](https://openai.com/business-data/), [OpenAI API data controls](https://developers.openai.com/api/docs/guides/your-data?article_id=8510)
