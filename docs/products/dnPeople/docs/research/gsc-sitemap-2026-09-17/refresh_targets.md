# Refresh targets — GSC sitemap research

- Recheck Google Search Console Sitemaps status after the first production submission.
- Record submitted URL count, indexed URL count, and top exclusion reasons.
- Recheck `robots.txt` and `sitemap.xml` after every domain, hosting, CDN, or routing change.
- Replace dynamic sitemap timestamps with content-derived timestamps when the content data model supports it.
- Review whether `/signup`, legal pages, careers, and `/docs` should remain indexable based on search intent and content quality.
- Refresh official Google documentation before changing the submission workflow.
