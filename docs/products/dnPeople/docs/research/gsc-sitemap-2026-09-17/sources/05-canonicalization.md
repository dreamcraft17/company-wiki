# Source 05 — Canonicalization

- URL: https://developers.google.com/search/docs/crawling-indexing/canonicalization
- Type: Google Search Central, primary
- Used for: canonical URL signals

> “Google then chooses the page…”

Key notes: Google selects a representative canonical from signals including redirects, sitemap presence, and canonical annotations; the site should not assume its preferred URL is automatically chosen.
