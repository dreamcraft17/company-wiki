# Source 06 — Consolidate duplicate URLs

- URL: https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls
- Type: Google Search Central, primary
- Used for: relative strength of sitemap and canonical signals

> “Sitemap inclusion: A weak signal…”

Key notes: Redirects are a stronger signal than `rel="canonical"`, and sitemap inclusion is weaker. Sitemap URLs should therefore agree with redirects, canonical tags, internal links, HTTPS, and host selection.
